Traits2

trait(open) trait Agent

The agent side. Implement what the agent can do and leave the rest: initialize and new_session and prompt are the three every agent has, the others have defaults that report themselves as unsupported.

trait(open) trait Client

The client side. update is the only method the protocol requires; the rest exist so the agent can ask for them, and a client that leaves one out answers -32601 when the agent asks.

fnserve_stdio
(agent : &@moonacp.Agent) -> Unit

Runs an agent on the process's own stdin and stdout until the client closes stdin. This is the transport an editor uses when it launches an agent: one JSON-RPC message per line, nothing else on stdout, diagnostics on stderr.

fnspawn
( client : &@moonacp.Client, command : Array[String], args? : Array[String], env? : Map[String, String], cwd? : StringView, ) -> Child

Starts command with args and connects to it as a client. The command is an absolute path or something the system can find on PATH; the first array element is the program.

fnChild::conn
(self : Child) -> @moonacp.Conn

The connection to the child, runnable and callable.

fnChild::close
(self : Child) -> Unit

Closes the child's input, which is how an agent learns the client is done: it finishes what it is doing and exits. The read side ends with it, so a task blocked on run comes back.
